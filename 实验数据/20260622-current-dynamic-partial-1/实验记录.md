# 2026-06-22 current dynamic partial frames = 1

## 本轮目标

继续降低低带宽模式下视频/秒表动态变化的画面拼接感。上一轮已经做到 `partial -> global` 在 1 帧后发生；本轮将动态 partial 阈值从 2 降到 1，让第一帧动态 partial 直接提升为 full-frame global，尽量消除那一帧低码率 partial 造成的视觉割裂。

## 改动摘要

- `GVT_STREAM_DIRTY_DYNAMIC_PARTIAL_FRAMES_DEFAULT` 从 `2` 改为 `1`。
- `scripts/gvt-qm-run` 默认 `DIRTY_DYNAMIC_PARTIAL_FRAMES=1`。
- `deploy/gvt-qm/win10.conf.example` 和 `SERVER.md` 同步说明。
- 远端 `/etc/gvt-qm/win10-external.conf` 显式追加/设置：

```text
DIRTY_DYNAMIC_PARTIAL_FRAMES=1
```

## 取舍

- 优点：最大限度避免普通 viewer 下低码率 partial 引入的动态拼接感。
- 代价：秒表、视频、窗口动画这类动态变化会更频繁使用 full-frame global，带宽会高于 `DIRTY_DYNAMIC_PARTIAL_FRAMES=2`。
- 静态背景收益仍保留：本轮 smoke 里 `dirty_skipped=1166`，动态验证后累计也有大量 `dirty_skipped`。
