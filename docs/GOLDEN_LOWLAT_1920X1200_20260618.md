## Source Shape

The golden QEMU backend source is captured in:

- `src/qemu/gvt-stream-low-latency-baseline.c`

This version keeps the 2026-06-18 09:41 wall-clock PTS fix:

- `last_encode_wall_ms`
- `gvt_stream_stamp_buffer()`
- DMABUF and CPU push paths stamp buffers using real wall-clock deltas.

This version intentionally does not include later experiments:

- no `pump_timer`
- no `rtpwatch` / `udp_rendered` self-heal logic
- no `GVT_STREAM_DMABUF_STALE_CPU_MS`
- no stale CPU fallback

Those later experiments helped diagnose long-idle and blue-frame issues, but
they increased timing complexity and were not part of the user-confirmed
artifact-free low-latency baseline.
